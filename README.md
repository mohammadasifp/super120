**Super120** is my personal coding practice repository where I regularly upload solutions to programming problems, data structures, algorithms, and academic assignments completed as part of the **Super120** program.

The goal of this repository is to improve problem-solving skills, strengthen programming fundamentals, and prepare for technical interviews and placement opportunities.
